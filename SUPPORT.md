# Getting help

The Tech-Lead Stack is maintained by one person in their own time. Support is
best-effort, with no guaranteed response time.

## Where to go

| You want to…                    | Go here                                                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Ask a question or share an idea | [GitHub Discussions](https://github.com/bronz3beard/ai.tech-lead-stack/discussions)                                |
| Report a bug                    | [Open a bug report](https://github.com/bronz3beard/ai.tech-lead-stack/issues/new?template=bug_report.md)           |
| Suggest a feature               | [Open a feature request](https://github.com/bronz3beard/ai.tech-lead-stack/issues/new?template=feature_request.md) |
| Report a security vulnerability | **Not an issue.** Follow [SECURITY.md](SECURITY.md) to report it privately.                                        |
| Contribute a fix or feature     | Read [CONTRIBUTING.md](CONTRIBUTING.md)                                                                            |

Before asking, check the [documentation](README.md#documentation) and search
existing issues and discussions. Someone may already have the answer.

## What is supported

Only the latest release and the `main` branch are supported. If you are on an
older version, upgrade first and check whether the problem is still there.
